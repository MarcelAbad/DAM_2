UMBRA CRM - CRM de Django para una discoteca
============================================

CREDENCIALES
  Usuario: admin
  Clave:   admin1234
  (Se crean solas con el comando cargar_ejemplo)

CÓMO ARRANCAR (en un equipo limpio)
  Windows:    doble clic en iniciar.bat
  Linux/Mac:  bash iniciar.sh
  Después abre http://127.0.0.1:8000/
  (El script crea el entorno virtual, instala Django, aplica las migraciones y carga los datos de ejemplo.)

PRUEBAS AUTOMÁTICAS
  python manage.py test      -> 19 pruebas (una por cada tarea del enunciado)
